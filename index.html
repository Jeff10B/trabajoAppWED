Lector de Facturas

Proyecto desarrollado para facilitar la lectura y extracción de información de facturas de manera automatizada. La aplicación permite analizar una factura y obtener datos importantes como número de factura, fecha, proveedor, productos y valores registrados.

El objetivo del proyecto es reducir el ingreso manual de información y facilitar la organización y gestión de los datos obtenidos de las facturas.

Tecnologías utilizadas:

  • Python
  • Procesamiento de documentos
  • OCR
  • HTML
  • MySQL
